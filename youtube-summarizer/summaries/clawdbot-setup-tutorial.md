# ClawdBot Setup Tutorial Summary

**Video:** [ClawdBot is the most powerful AI tool I've ever used](https://www.youtube.com/watch?v=Qkqe-uRhQJE)
**Category:** Setup

## Overview
ClawdBot (now OpenClaw) is a 24/7 AI agent that runs on your computer and works as a personal AI employee. It can control your computer, has infinite memory, and is accessible via messaging apps like Telegram, WhatsApp, or iMessage.

## Key Features
- **Computer Control:** Can open browsers, work in Google Docs, Apple Notes, Notion, send emails, and more
- **Infinite Memory:** Complex memory system saves everything you discuss; learns your preferences over time
- **Messaging Integration:** Access via Telegram, WhatsApp, iMessage, Discord, Slack, etc.
- **Proactive Work:** Writes morning briefings, newsletter drafts, and YouTube scripts without prompting
- **Vibe Coding:** Can use Claude Code, Codex, and other coding platforms autonomously

## Hardware Options

| Option | Cost | Best For |
|--------|------|----------|
| VPS (AWS, etc.) | ~Free-$20/mo | Budget users, beginners |
| Mac Mini (base) | $600 | Apple ecosystem, convenience |
| Mac Studio | $10K+ | Running local models, unlimited free usage |

**Recommendation:** Start with a VPS or spare computer. Mac Mini is optional but provides better Apple integration.

## AI Model Selection

### Brain Model (Primary)
| Model | Cost | Personality | Intelligence |
|-------|------|-------------|--------------|
| Claude Opus 4.5 | $200/mo (Max plan) | Best | Highest |
| ChatGPT 5.2 | ~$100/mo | Robotic | High |
| MiniMax | ~$10/mo | Good | Good |

**Key insight:** Personality matters! Opus feels human, which makes the experience much more enjoyable.

## Setup Process
1. Go to **claw.bot** (cl-a-w.bot)
2. Copy the quick start command
3. Paste in terminal and hit enter
4. Choose your AI provider (Anthropic recommended)
5. Select skills you want (Apple Notes, Notion, Claude Code, etc.)
6. Set up messaging service (Telegram recommended)

## Best Practices
- Give ClawdBot its own separate email and accounts
- Run on separate hardware or VPS to avoid unintended actions on personal files
- Use Telegram for dedicated AI communication (separate from personal chats)
- Name your bot (e.g., "Henry") - makes interaction more fun

## Sample Use Cases Demonstrated
- Building a Kanban board via text while at Chick-fil-A
- Morning briefings with weather, AI news, and overnight work summaries
- Thumbnail editing using AI services like Nano Banana Pro
